# Habit Quest

**HTML CA 2 project**

Habit Quest is a small browser game that turns daily habits into progress in a creature-battling game. Add habits, mark them done, earn XP, and use your progress to unlock creatures. You can also challenge local rivals against the computer or in pass-and-play PvP.

## Run the project

Open `index.html` in a modern web browser. There are no build steps or package installations.

Progress is saved in the browser's local storage, so it stays on the same browser and device.

## How to play

- Add habits on the **Habits** screen and mark them complete each day.
- Completing habits earns XP and helps recruit the rival creature.
- Choose from your unlocked creatures and start a battle.
- Earn points through habits to enter a duel. Pick **vs computer** or **Local PvP** to play pass-and-play with another person.
- Find creatures in the collection as you progress.

## Project files

- `index.html` — page structure and game screens.
- `style.css` and `styles/` — page styles, split into base, layout, battle, panels, screens, and responsive styles.
- `script.js` — habits, creature selection, progression, and regular battles.
- `duels.js` — rival profiles and computer or local PvP duels.
- `assets/` — backgrounds and character sprites.
